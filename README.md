# ocpp-bench

OCPP 1.6J and 2.0.1 central system (CSMS) and a station simulator for driving it, or any other CSMS, through the kind of adversarial scenarios you see when you actually run a charging network: reconnect storms, flapping chargers, late messages, duplicate transactions, oversized payloads.

Full README lands in the final commit of the first pass; see `docs/` for ADRs and failure modes.
